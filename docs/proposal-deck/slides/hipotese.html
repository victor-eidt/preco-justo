A hipótese

O modelo de linguagem sabe quanto as coisas custam no mundo. Os dados brasileiros ensinam a correção local.

Se isso for verdade, o pipeline completo — Jev descrevendo, modelo corrigindo — supera tanto o modelo treinado sozinho quanto o Jev sozinho. É exatamente isso que o trabalho vai medir.

~75s. Slide de respiro. Pare de falar por um segundo depois de ler o título. Explique a intuição: um LLM foi treinado em muito texto e tem noção de preço de mercado. Mas compra pública brasileira tem desvios sistemáticos — tributação, custo de licitar, diferença regional, escala. Essa diferença está nos dados, não no modelo. A frase de baixo é a hipótese testável. Ela tem que superar DOIS baselines, não um. Esse é o desenho do experimento. Se perguntarem "e se não superar?": respondo que reporto assim mesmo, com o gráfico. É por isso que a avaliação é uma escada e não um número solto. Próximo slide.
