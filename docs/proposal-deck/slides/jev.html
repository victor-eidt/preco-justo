~110s. O slide que explica a tecnologia. Use o MESMO item do slide anterior - o microcomputador all in one - para a sala acompanhar. Esses numeros sao a saida real do Jev para aquele registro. Comece pela frase do topo: é um LLM. Parte de um modelo pré-treinado como o ChatGPT, mas o pós-treinamento é outro — em vez de otimizar para gerar texto que agrada o leitor, ele é treinado para devolver decisões e probabilidades calibradas. Calibrado quer dizer: de todas as vezes que ele disser 0,80, ele precisa acertar em torno de 80% delas. É isso que permite usar o número como limiar no código. Os três cartões são os três tipos de pergunta. Diga o exemplo de cada um, sem ler tudo. O quarto cartão é o volume: 19 perguntas numa chamada só, virando 33 colunas. A frase final é a ponte para o próximo slide: texto livre vira matriz. E a diferença para TF-IDF é que cada coluna tem NOME e SIGNIFICADO. Se perguntarem por que não usar o ChatGPT direto: porque a resposta dele não vem calibrada, muda entre execuções e não deixa rastro auditável. Eu preciso de número que signifique alguma coisa.
